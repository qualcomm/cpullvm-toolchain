# Release Notes

- CPULLVM project releases are documented in [CHANGELOG](CHANGELOG.md)
- Release notes for LLVM, Clang and sub-projects can be found in the [llvm.org download page](https://releases.llvm.org/download.html)
- For ELD changes check the [project repository documentation](https://github.com/qualcomm/eld)
- Release notes for picolibc can be found in the [project download page](https://github.com/picolibc/picolibc/releases)
- For musl-embedded changes check the [project repository documentation](https://github.com/qualcomm/musl-embedded/blob/main/qualcomm-software/README.md)

## [23.1.0]
- Release built with [LLVM 23.1.0](https://releases.llvm.org/23.1.0/docs/ReleaseNotes.html), [Clang 23.1.0](https://releases.llvm.org/23.1.0/tools/clang/docs/ReleaseNotes.html), [ELD 23.x_lto_linker_scripts](https://github.com/qualcomm/eld/tree/release/23.x_lto_linker_scripts), [picolibc after 1.8.10](https://github.com/picolibc/picolibc/commit/01254932e8e81085817ed61fd858648584ffe37c), [picolibc 1.8.12](https://github.com/picolibc/picolibc/releases/tag/1.8.12) and [musl 1.2.5](https://musl.libc.org/)
- Release build includes additional [patches](/qualcomm-software/patches) for LLVM 23.1.0, musl 1.2.5, picolibc 1.8.10 and picolibc 1.8.12
